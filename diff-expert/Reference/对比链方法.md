# 对比链方法论（k5 沉淀，2026-08-19~21）

差异对比专家技能包的方法论来源：Dify chatflow k5 的对比链
（分类器2 → 提取参数 → 读索引 → 匹配 → 读两版 → difflib 分块 → 差异表 LLM）。
10 题精选评测：7 全对 / 1 半对 / 2 错 = 70%，对比链核心合格。
本文档记录方法论与踩过的坑，供技能包演进参考。

## 数据源

- MinIO：`http://localhost:9000`，桶 `dify-files`，凭据 minioadmin/minioadmin123
- 索引：`_index.json` → `{"标准": [6 个], "偏离": [5 个]}`
- 文档：`标准/<文件名>.docx.md` / `偏离/<文件名>.docx.md`（入库前已清洗）
- 11 文件：标准 6（Appendix A 210909 双语 / B 信息安全 / C DPA 数据修改 / D Quotation_Template xlsx / F Code of Conduct / Master Agreement 汽车合同中台）+ 偏离 5（Appendix A 230404 双语 / A1 Deviation form ABC / C 委托处理 / E price list xlsx / Framework Agreement TECH Platform）

## 核心链路（5 步）

1. **分类过滤**：只接"标准 vs 偏离差异"类问题；单文档问答/检索类直接拒
2. **提取参数**：topic（文档主题）+ 隐含版本对（标准/偏离）
3. **定位**：读索引 → 双侧各自模糊匹配（包含关系优先，SequenceMatcher 兜底）→ 双侧都 ≥0.6 才算 matched
4. **读两版 + difflib**：按行对比，忽略空白/空行，分批（800 行/批）防内存
5. **LLM 提炼**：差异块 → 差异表（条款/类型/两侧内容/实质影响），忽略噪声

## 血泪坑（都踩过）

### 1. topic 提取与匹配
- 用户说"主协议"时，标准侧是 Master Agreement、偏离侧是 Framework Agreement —— **文件名不相似，模糊匹配分 0.38**，语义同源但算法认不出 → 用成对映射（PAIR_ALIASES）直接锁定
- 用户说法五花八门："报价单 / price list / 价格表 / 报价" → 别名映射（ALIASES）
- 匹配失败不要硬猜，把 alternatives 给用户确认

### 2. 检索退化（D09 案例）
- 依赖检索接口定位文档会退化（top_k 截断、embedding 相似度噪声）→ **改用索引直读**（_index.json 精确清单），稳定不退化

### 3. 话题漏差异（C04 案例）
- 话题过滤太严会把"部分对比意图"的问题误拒；太松会把非对比问题放进来 → 第一道门槛只挡明确的非对比类（单文档问答/检索），模糊的对比意图放行后在第 1 步追问澄清

### 4. sanitize 残留
- 文档清洗时在开头留下统计头（"- 原始字符数：…"、"步骤字符数：…"、"- 去除重复分块"）→ 两侧数字必然不同 → diff 产生噪声块 → LLM 规则里显式忽略
- 水印（VOLVO 被打散成 v o L v o）、脚注编号 N(17)/N(21) 等也是噪声源 → 忽略规则要全
- 双语文档：英文相同、仅中文翻译措辞差异且含义一致 → 不报；含义实质不同 → 报

### 5. 截断
- 16000 字符截断会把长条款切在中间 → 差异块按行截断时保留行完整性（整行切，不切行内），并标记 truncated 提醒 LLM
- 大文档分批 diff（800 行/批）防 SequenceMatcher O(n·m) 内存爆炸

### 6. 差异块碎片化
- replace 块相邻合并（同型且首尾相接）→ 避免 50 条碎片
- LLM 提炼时要求"合并相邻同类差异，最多 20 条，不凑数"

## 评测参考（10 题精选）

- 7 全对 / 1 半对 / 2 错（70%）：对比链核心合格，问题定位/差异提取稳定
- 失败案例：D05 路由错位（话题分类误入）、D09 检索退化（已用索引直读修复）、C04 话题漏差异
- 元问题（"你觉得标准版哪里写得不好"）超越 k4：对比链的差异表能支撑评价类追问
